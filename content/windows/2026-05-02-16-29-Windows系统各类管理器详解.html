Core Components

四大核心管理器

Windows 系统运转的基石，理解它们是掌握系统管理的第一步

Ctrl+Shift+Esc

任务管理器

Taskmgr.exe

电脑的"进程监控与性能仪表盘"
  • 查看和管理正在运行的所有程序、进程、服务
  • 实时监控 CPU、内存、磁盘、网络、GPU 等硬件资源
  • 强制关闭无响应的程序；管理开机自启动项
快捷打开 taskmgr
Win+E

文件资源管理器

Explorer.exe

电脑的"文件管理外壳"，你每天都在使用它
  • 浏览和管理电脑中的所有文件、文件夹、磁盘、库
  • 提供桌面、任务栏、开始菜单等核心图形界面
  • 管理网络位置与系统导航架构
快捷打开 explorer
System

WebView 管理器

msedgewebview2.exe

应用内浏览器引擎的总控进程
  • 管理 Microsoft Edge WebView2 运行时环境
  • 支持 Office、Teams、Windows 小组件等显示网页内容
  • 即使不打开 Edge，这些进程也可能在后台运行
进程特征 多进程模型（Chrome 架构）
Kernel

窗口管理器

win32k.sys + dwm.exe

系统内核级别的窗口调度中心
  • 负责所有窗口的创建、显示、移动、调整大小
  • 管理窗口层级关系、动画效果与多显示器布局
  • 不是独立可执行文件，由内核组件共同实现
核心组件 DWM
System Tools

其他常见管理器

系统管理员和高级用户的必备工具箱

管理器名称 核心功能 打开命令
设备管理器
管理所有硬件设备，安装/更新/卸载驱动程序，启用/禁用设备
devmgmt.msc
磁盘管理器
管理硬盘分区、格式化磁盘、创建/删除/扩展分区、分配盘符
diskmgmt.msc
服务管理器
管理系统后台服务，设置启动类型（自动/手动/禁用），启动/停止服务
services.msc
本地用户和组
管理本地计算机的用户账户和用户组，设置权限和密码
lusrmgr.msc
计算机管理
集成设备管理器、磁盘管理、服务、事件查看器的综合控制台
compmgmt.msc
事件查看器
查看系统、应用程序、安全等方面的日志，帮助排查系统错误
eventvwr.msc
本地组策略
配置系统安全策略、用户权限、软件安装等高级设置（专业版及以上）
gpedit.msc
注册表编辑器
查看和编辑 Windows 核心配置数据库（谨慎使用）
regedit

使用技巧

所有 .msc 文件都是 Microsoft 管理控制台（MMC）的插件，你可以通过 Win + R 打开"运行"对话框，直接输入命令快速启动对应的管理工具。

Win + R → 输入命令 → Enter 最快启动方式
